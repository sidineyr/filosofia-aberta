# Filosofia Aberta

**Uma pergunta leva à próxima.**

Projeto educacional **experimental, gratuito e em desenvolvimento** para leitura orientada dos clássicos da Filosofia, concebido por **Sidiney Rodrigues**.

## Estado atual

O site possui um módulo piloto disponível — **Sócrates via *Apologia* de Platão**. Os demais pensadores apresentados no percurso são um roteiro editorial planejado e não devem ser confundidos com aulas já concluídas.

O projeto é tratado como um laboratório pedagógico aberto: conteúdo, navegação e referências podem ser corrigidos quando novas verificações indicarem necessidade.

## Objetivo

Ajudar iniciantes e leitores em geral a aprender a ler fontes filosóficas primárias com autonomia, contexto e rigor, distinguindo:

- texto primário;
- testemunho histórico;
- referência acadêmica;
- interpretação;
- síntese pedagógica;
- resposta pessoal do estudante.

## Princípio de navegação

O Filosofia Aberta não deve funcionar como uma lista de links. Cada referência externa tem uma função no percurso. Fontes externas abrem em nova aba para preservar a página principal como fio de investigação: **abrir, consultar, voltar e ligar**.

## Fontes verificadas do módulo piloto

- **Stanford Encyclopedia of Philosophy — “Socrates”**: contexto e problema socrático.
- **Perseus Catalog — Plato, *Apology***: identificação bibliográfica da obra.
- **Project Gutenberg — *Apology*, Benjamin Jowett**: tradução inglesa histórica usada na leitura da passagem 38a.
- **Internet Encyclopedia of Philosophy — “Socrates”**: comparação e aprofundamento.

## Descoberta e indexação

O repositório contém:

- `robots.txt` permitindo rastreamento;
- `sitemap.xml` com URL canônica;
- `<link rel="canonical">` e metadados de indexação na página;
- chave pública para **IndexNow**;
- workflow preparado para notificar mecanismos compatíveis com IndexNow após um deploy bem-sucedido.

**Importante:** preparar ou enviar uma URL para mecanismos de pesquisa não garante indexação. Google Search Console e Bing Webmaster Tools devem ser usados para acompanhar descoberta, rastreamento e indexação reais.
